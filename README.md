# Rooms Mod (NeoForge 1.21.1)

Roblox Rooms 系エクスペリエンスを参考にした試作Modです。

> エンティティの行動はネタバレになるため、この README には **名前と出現セクションだけ** を載せています。

## 動作環境

- Minecraft **1.21.1**
- NeoForge **21.1.x**
- Java **21**

## 導入・ビルド

1. 配布されている JAR（例：`roomsmod-0.1.0.jar`）をクライアント／サーバーの `mods` フォルダに入れます。
2. 自分でビルドする場合：
   ```sh
   sh ./gradlew build
   # → build/libs/roomsmod-0.1.0.jar
   ```
3. 設定（サーバー設定：ワールドの `serverconfig/roomsmod-server.toml`）
   - `spawnInRooms`（既定 `true`）：初回ログイン時と、ベッド／リスポーンアンカーなしでのリスポーン時にロビーへ送ります。

## 遊び方

- 初回参加時（または `/rooms enter`）に Rooms ディメンションのロビーへ移動します。
- ロビー奥の扉を開けると部屋 1 が生成されます。以降、各部屋の出口の扉を開けるたびに次の部屋が生成されます。
- 開けた扉は閉められません（一部の例外を除く）。
- 部屋の中では作業台やチェストなどのブロック操作はできません（ロッカー・隠れテーブル・扉・ロビーのパネルなど、Mod の仕掛けだけ操作できます）。
- どの部屋にも隠れ場所（ロッカー／隠れテーブル）があります。右クリックで出入りします。

## セクション

部屋は「セクション」ごとに見た目と出現エンティティが変わります。番号はセクションごとに 1 から数えます（例：`V-001`）。

| セクション | 部屋の雰囲気 | 番号 |
|---|---|---|
| **B** | 大きめの部屋。箱型・廊下・ホール・高天井・L字など | `B-001`〜 |
| **V**（Village） | 村の小さな家。2部屋つながり・2階建てなど | `V-001`〜 |
| **GK**（学校） | 教室・廊下・準備室。B と V の中間（B 寄り）の大きさ | `GK-001`〜 |
| **U** | まっすぐな廊下だけの部屋。長さはいろいろ | `U-001`〜 |

- どのセクションも **500 部屋** です。順番は **B → V → GK → U** で、500 部屋ごとに自動で次のセクションへ切り替わります（例：`B-500` の次は `V-001`）。
- U の 500 部屋目より先は、今のところ U がそのまま続きます（`U-501`…。この先の扱いは未定です）。
- テスト用のセクション **PLACEHOLDER**（`PLACEHOLDER-001`〜）もあります。上の順番には入らず、ロビーのパネルにも出ません。`/rooms section placeholder` でだけ始まり、始めるとずっと続きます。エンティティは自然には出ません。
- 途中のセクションから始めるときは、ロビーの **スタート選択パネル**、または `/rooms section` を使います（旧称 A。`a` も B の別名として使えます）。
- 奥へ進むほど部屋は少しずつ暗くなります。

## ロビーのパネル

### スタート選択パネル（入口から出口の扉を向いて左の壁）

| ブロック | 操作 |
|---|---|
| 水色（SECTION） | セクションを切り替え（B → V → GK → U、追加セクションも自動で並びます）。スニーク＋右クリックで逆順 |
| 赤（−）／緑（＋） | スタート部屋の番号：1, 50, 100, 150, 200, 250, 300, 400, 500 |
| 中央の看板 | 現在の選択（例：`GK-150`） |
| 金（GO） | そのセクションのその部屋から開始（ロビーを作り直して部屋を生成し、ワープ）。以降は 500 部屋ごとに次のセクションへ |

- 選択はサーバー全体で共有です。
- GO は `/rooms to` と同じく **全員の進行をリセット** します。
- 部屋の生成は数 tick に分けて行われます（生成中はアクションバーに進捗が表示されます）。生成中はもう一度 GO できません。

### ハードモード切替（左の壁、スタート選択パネルの出口側）

ボタンを右クリックするとハードモードの ON / OFF が切り替わります（看板：`HARD MODE ON` は赤、`OFF` は灰色）。
設定はサーバー全員で共有され、ワールドに保存されます。`/rooms hard on|off|status` でも操作できます。

- ON のあいだは、**すべてのセクション**のエンティティがどのセクションの部屋にも出現します。
- 各エンティティが出始める部屋は、通常どおり「今いるセクション内の部屋番号」で判定します。
- 排他ルール（同時に出ない組み合わせ）はセクションをまたいでもそのまま有効で、扉1枚あたりの出現は最大 3 体です。
- エンティティは通常より出やすく、少し手ごわくなります。何かが去ったあとも油断しないでください。
- ハードモードでは、一部のエンティティは他のエンティティと同時には出現しません。
- 必要な設備（窓・隠れ場所など）がない部屋では、そのエンティティは出現しません。
- ON のときは扉を開けるたびにアクションバーに `☠ HARD MODE` と部屋番号が表示されます。

### 最奥の部屋パネル（出口の扉の右側）

- 看板に、生成済みでいちばん奥の部屋の番号（例：`GK-306`）が表示され、部屋が増えるたびに更新されます。
- エメラルドブロック（または看板）を右クリックすると、その部屋へワープします（進行はリセットされません）。

パネルは壊せません。ロビーに入るたびに作り直されるので、既存のワールドでも次にロビーへ入れば設置されます。

## 懐中電灯と電池

- 初めて Rooms ディメンションに入ると、懐中電灯が 1 本もらえます。死亡してリスポーンしたとき、懐中電灯を持っていなければ満充電のものがもう一度もらえます（重複はしません）。
- 右クリックで ON／OFF。ON の間は前方を照らし、電池を消費します。
- 残量はアイテムのバーとアクションバー（`電池 0:42` など）で確認できます。エンティティの表示が出ている間は、そちらが優先されます。
- 電池は一部の部屋の床に落ちています。懐中電灯の電池が切れると、予備の電池を自動で装填します。

## スタミナ

ルーム（ロビーを含む）の中では、満腹度の代わりにスタミナ（0〜100）を使います。画面右下の満腹度バーは水色のスタミナバー（`STAMINA 64` など）に置き換わります。

- ダッシュ中に減ります（満タンから約 8 秒で 0）。歩いている間は約 6 秒、立ち止まっている間は約 4 秒で満タンまで回復します。ダッシュ中は回復しません。
- 0 になると息切れしてダッシュが止まり、スタミナが 25 に戻るまでダッシュできません。息切れ中はバーが暗い赤色になり、`EXHAUSTED` と表示されます。
- ルーム内では空腹で体力が回復することも、餓死することもありません。体力の回復手段は包帯だけです。食べ物は食べられますが、効果はありません。
- ルームに入るときの満腹度は保存され、ルームを出ると元に戻ります。
- クリエイティブでもスタミナは減ります（飛行中は減りません）。スペクテイターは対象外です。

## 包帯

- 右クリックを約 1.5 秒長押しすると、使い終わった時点で体力が 25 回復します（ルーム内の最大体力は 100）。
- 途中で手を離すと何も起きず、包帯も減りません。体力が満タンのときは使えません。
- 最大 8 個までスタックできます。約 12% の部屋の床に落ちています（電池とは別の抽選）。ロビーには落ちていません。
- ルーム内ではクリエイティブでも使えます（クリエイティブでは減りません）。

| セクション | エンティティ |
|---|---|
| B | B-20, B-40, B-15, B-30, B-50, B-70, B-90, B-110, B-130, B-155, B-180, B-205, B-230, B-260, B-290 |
| V | V-10, V-25-T, V-25-L, V25-BUFFED, V-50, V-100 |
| GK | GK-10, GK-25, GK-45, GK-65, GK-85, GK-105, GK-125, GK-145, GK-165, GK-185, GK-205, GK-225, GK-245, GK-270, GK-300 |
| U | U-20, U-60, U-120, U-200, U-300 |

- どのエンティティにも前触れ（音・見た目・表示）と対処法があります。
- 同時に出ると理不尽になる組み合わせは、同時には出ないようになっています。
- エンティティが同じ場所に居続けるのは最大でも 2 分未満です（GK は 100 秒以内）。

## デバッグモード

`/rooms debug on` で有効になります（OP 権限）。

- 部屋の生成、エンティティの出現・消滅、隠れ場所、パネル操作などの通知がチャットとサーバーログに出ます。
- **死亡回避**：デバッグ中は死亡だけが取り消されます。ダメージは通常どおり受けます。
- `/rooms debug section` で現在のセクションとセクション表を表示します。

## コマンド

`/rooms` 以下のコマンドです。「OP」は権限レベル 2 が必要です。

| コマンド | 権限 | 内容 |
|---|---|---|
| `/rooms enter` | 全員 | ロビーへ移動（ロビーを作り直し、進行をリセット） |
| `/rooms to <1-500>` | 全員 | ロビーから部屋 N まで生成してワープ（進行をリセット） |
| `/rooms section <id>` / `/rooms section <id> now` | OP | 次に生成する部屋からセクション `<id>`（`b` / `v` / `gk` / `u`。旧 `a` は `b` の別名）を開始。以降は 500 部屋ごとに次のセクション |
| `/rooms section <id> <部屋番号>` | OP | セクション `<id>` を指定した通し番号の部屋から開始（以降は同じく 500 部屋ごと） |
| `/rooms section reset` | OP | セクション表を既定（B → V → GK → U、各 500 部屋）に戻す |
| `/rooms spawn <id>` | OP | エンティティを強制出現（同じ排他グループが生存中なら出現しません） |
| `/rooms give flashlight` | OP | 満充電の懐中電灯をもらう |
| `/rooms give battery [個数]` | OP | 電池をもらう（1〜64） |
| `/rooms give bandage [個数]` | OP | 包帯をもらう（1〜64） |
| `/rooms hard on` / `off` | OP | ハードモードの切り替え（サーバー全体・ワールドに保存） |
| `/rooms hard status` | 全員 | ハードモードの状態を表示 |
| `/rooms debug on` / `off` / `status` | OP | デバッグモードの切り替え・確認 |
| `/rooms debug section` | OP | 現在のセクション・番号・セクション表を表示 |
| `/rooms deepest` | 全員 | （未実装の予約コマンド。最奥への移動はロビーのパネルを使ってください） |

`/rooms spawn` の id：`b20` `b40` `b15` `b30` `b50` `b70` `b90` `b110` `b130` `b155` `b180` `b205` `b230` `b260` `b290`
 `v10` `v25t` `v25l` `v25buffed`（`v25buffed table` / `v25buffed locker`）`v100` `v50`
`gk10` `gk25` `gk45` `gk65` `gk85` `gk105` `gk125` `gk145` `gk165` `gk185` `gk205` `gk225` `gk245` `gk270` `gk300`
 `u20` `u60` `u120` `u200` `u300`
 `placeholder32767` `placeholder65535` `placeholder2147483648`（テスト用。PLACEHOLDER の部屋以外でも出せます）

B / GK / U の番号はそのエンティティが出始めるセクション内の部屋番号です。

### 例

- GK を最初から：ロビーの左の壁で `GK-001` を選んで GO（または `/rooms section gk 1` → `/rooms to 1`）
- V の 100 部屋目から：ロビーで `V-100` を選んで GO
- U を最初から：ロビーで `U-001` を選んで GO（または `/rooms section u 1` → `/rooms to 1`）
