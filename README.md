# Rooms Mod (NeoForge 1.21.1)

Roblox Rooms 系エクスペリエンスを参考にした試作Modです。

## 現在の状態（試しに作成）

- 基本的なNeoForge 1.21.1プロジェクト構造
- カスタムディメンションのベース（実装予定）
- ロビー生成・次の部屋生成のロジック骨格
- A-60エンティティの骨格（レイキャスト有限距離対応）

## ビルド方法

1. Java 21 をインストール
2. このディレクトリで `./gradlew build` を実行
3. 生成されたJARを mods フォルダに入れる

## 次に実装予定

- ロビー（Worldspawn、椅子のみ、幅20x奥行き32）
- 扉を開けたら次の部屋生成（5種類バリエーション）
- 看板 A-001〜
- A-60 の突進・視線ダメージ（半径20-25ブロック）

詳細はソース内コメントを参照。
