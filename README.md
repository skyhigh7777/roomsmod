# SRT's Rooms : Deep Corridors (NeoForge 1.21.1)

Mod ID: `roomsmod`（表示名のみ変更。ID・パッケージ・JAR 名 `roomsmod-0.1.0.jar`・セーブ互換はそのまま）

Roblox Rooms 系エクスペリエンスを参考にした試作Modです。

> エンティティの行動はネタバレになるため、この README には **名前と出現セクションだけ** を載せています。

## 動作環境

- Minecraft **1.21.1**
- NeoForge **21.1.x**
- Java **21**

## 導入・ビルド

1. 配布されている JAR（例：`roomsmod-0.1.0.jar`）をクライアント／サーバーの `mods` フォルダに入れます。
2. 自分でビルドする場合：
   ```sh
   sh ./gradlew build
   # → build/libs/roomsmod-0.1.0.jar
   ```
3. 設定（サーバー設定：ワールドの `serverconfig/roomsmod-server.toml`）
   - `spawnInRooms`（既定 `true`）：初回ログイン時と、ベッド／リスポーンアンカーなしでのリスポーン時にロビーへ送ります。

## 遊び方

- 初回参加時（または `/rooms restart`）に Rooms ディメンションのロビーへ移動します。
- ロビー奥の扉を開けると部屋 1 が生成されます。以降、各部屋の出口の扉を開けるたびに次の部屋が生成されます。
- 開けた扉は閉められません（一部の例外を除く）。
- 部屋の中では作業台やチェストなどのブロック操作はできません（ロッカー・隠れテーブル・扉・ロビーのパネルなど、Mod の仕掛けだけ操作できます）。
- どの部屋にも隠れ場所（ロッカー／隠れテーブル）があります。右クリックで出入りします。

## セクション

部屋は「セクション」ごとに見た目と出現エンティティが変わります。番号はセクションごとに 1 から数えます（例：`V-001`）。

| セクション | 部屋の雰囲気 | 番号 |
|---|---|---|
| **V**（Village） | 村の小さな家。2部屋つながり・2階建てなど | `V-001`〜 |
| **B** | 大きめの部屋。箱型・廊下・ホール・高天井・L字など | `B-001`〜 |
| **U** | まっすぐな廊下だけの部屋。長さはいろいろ | `U-001`〜 |
| **S**（School） | 教室・廊下・準備室。B と V の中間（B 寄り）の大きさ | `S-001`〜 |
| **A**（Abyss） | 底の見えない縦穴。落ち続けながら進む（扉なし・後戻りなし） | `A-001`〜 |

- どのセクションも **500 部屋** です。順番は **V → B → U → S → A** で、ロビーの扉の先が `V-001`、500 部屋ごとに自動で次のセクションへ切り替わります（例：`V-500` の次は `B-001`）。
- A の 500 部屋目より先は、A がそのまま続きます（`A-501`…）。
- 病棟のセクション **H**（`H-001`〜`H-500`）もあります。既定ではロックされていて、ロック中は上の順番に入りません（S の次は A）。`/rooms admin section h unlock` で解放すると **S → H → A** の順になり、ロビーのパネルでも選べます。 H には病棟専用のエンティティ（H-30 / H-90 / H-150 / H-260）も出ます。
- 水没区画のセクション **F**（`F-001`〜`F-500`）もあります。床がくるぶしまでの浅い水に覆われていて（溺れることはありません）、ダッシュ時のスタミナ消費が 1.5 倍になります。F には水没区画専用のエンティティ（F-5 / F-35 / F-100 / F-200）が出ます。既定ではロックされていて、`/rooms admin section f unlock` で解放すると **S → F → A**（H も解放していれば **S → H → F → A**）の順になります。
- テスト用のセクション **PLACEHOLDER**（`PLACEHOLDER-001`〜）もあります。上の順番には入らず、ロビーのパネルにも出ません。`/rooms admin section placeholder unlock` で解放したあと `/rooms admin tp placeholder 1` などでだけ始まり、始めるとずっと続きます。エンティティは自然には出ません。
- 途中のセクションから始めるときは、ロビーの **スタート選択パネル**、または `/rooms admin section`（オーナーのみ）を使います。
- 奥へ進むほど部屋は少しずつ暗くなります。

### A（Abyss）

- S の最後の扉の先は小部屋で、床の穴から縦穴へ落ちます。一度落ちると上へは戻れません。
- 縦穴の中では落下ダメージはありません。落下速度には上限があり（約 12 ブロック/秒）、スニーク中はゆっくり（約半分）落ちます。
- 一定の深さを落ちるごとに 1 部屋進みます（壁の看板に `A-002` などの番号）。
- 2〜3 部屋ごとに壁に横穴があり、ロッカーがあります。落ちながら横へ動けば入れます。

## ロビーのパネル

### スタート選択パネル（入口から出口の扉を向いて左の壁）

| ブロック | 操作 |
|---|---|
| 水色（SECTION） | セクションを切り替え（V → B → U → S → A、追加セクションも自動で並びます）。スニーク＋右クリックで逆順 |
| 赤（−）／緑（＋） | スタート部屋の番号：1, 50, 100, 150, 200, 250, 300, 400, 500 |
| 中央の看板 | 現在の選択（例：`S-150`） |
| 金（GO） | そのセクションのその部屋から開始（ロビーを作り直して部屋を生成し、ワープ）。以降は 500 部屋ごとに次のセクションへ |

- 選択はサーバー全体で共有です。
- GO は `/rooms admin to` と同じく **全員の進行をリセット** します。
- 部屋の生成は数 tick に分けて行われます（生成中はアクションバーに進捗が表示されます）。生成中はもう一度 GO できません。

### ハードモード切替（左の壁、スタート選択パネルの出口側）

ボタンを右クリックするとハードモードの ON / OFF が切り替わります（看板：`HARD MODE ON` は赤、`OFF` は灰色）。
設定はサーバー全員で共有され、ワールドに保存されます。`/rooms admin hard on|off`（オーナーのみ）でも切り替えられ、`/rooms hard status` で誰でも確認できます。

- ON のあいだは、**すべてのセクション**のエンティティがどのセクションの部屋にも出現します。
- 各エンティティが出始める部屋は、通常どおり「今いるセクション内の部屋番号」で判定します。
- 排他ルール（同時に出ない組み合わせ）はセクションをまたいでもそのまま有効で、扉1枚あたりの出現は最大 3 体です。
- エンティティは通常より出やすく、少し手ごわくなります。何かが去ったあとも油断しないでください。
- ハードモードでは、一部のエンティティは他のエンティティと同時には出現しません。
- 必要な設備（窓・隠れ場所など）がない部屋では、そのエンティティは出現しません。
- 画面左下に今いる部屋の番号（例：`V-123`）が常に表示され、ハードモード中はその前に赤い `☠` が付きます。

### 最奥の部屋パネル（出口の扉の右側）

- 看板に、生成済みでいちばん奥の部屋の番号（例：`S-306`）が表示され、部屋が増えるたびに更新されます。
- エメラルドブロック（または看板）を右クリックすると、その部屋へワープします（進行はリセットされません）。

パネルは壊せません。ロビーに入るたびに作り直されるので、既存のワールドでも次にロビーへ入れば設置されます。

## 懐中電灯と電池

- 初めて Rooms ディメンションに入ると、懐中電灯が 1 本もらえます。死亡してリスポーンしたとき、懐中電灯を持っていなければ満充電のものがもう一度もらえます（重複はしません）。
- 右クリックで ON／OFF。ON の間は前方を照らし、電池を消費します。
- 残量はアイテムのバーとアクションバー（`電池 0:42` など）で確認できます。エンティティの表示が出ている間は、そちらが優先されます。
- 電池は一部の部屋の床に落ちています。懐中電灯の電池が切れると、予備の電池を自動で装填します。

## スタミナ

ルーム（ロビーを含む）の中では、満腹度の代わりにスタミナ（0〜100）を使います。画面右下の満腹度バーは水色のスタミナバー（`STAMINA 64` など）に置き換わります。

- ダッシュ中に減ります（満タンから約 8 秒で 0）。歩いている間は約 6 秒、立ち止まっている間は約 4 秒で満タンまで回復します。ダッシュ中は回復しません。
- 水没区画（F）の中ではダッシュ時の消費が 1.5 倍です。
- 0 になると息切れしてダッシュが止まり、スタミナが 25 に戻るまでダッシュできません。息切れ中はバーが暗い赤色になり、`EXHAUSTED` と表示されます。
- ルーム内では空腹で体力が回復することも、餓死することもありません。体力の回復手段は包帯だけです。食べ物は食べられますが、効果はありません。
- ルームに入るときの満腹度は保存され、ルームを出ると元に戻ります。
- クリエイティブでもスタミナは減ります（飛行中は減りません）。スペクテイターは対象外です。

## 包帯

- 右クリックを約 1.5 秒長押しすると、使い終わった時点で体力が 25 回復します（ルーム内の最大体力は 100）。
- 途中で手を離すと何も起きず、包帯も減りません。体力が満タンのときは使えません。
- 最大 8 個までスタックできます。約 12% の部屋の床に落ちています（電池とは別の抽選）。ロビーには落ちていません。
- ルーム内ではクリエイティブでも使えます（クリエイティブでは減りません）。

| U | U-20, U-60, U-120, U-200, U-300 |
| S | S-10, S-25, S-45, S-65, S-85, S-105, S-125, S-145, S-165, S-185, S-205, S-225, S-245, S-270, S-300 |

- どのエンティティにも前触れ（音・見た目・表示）と対処法があります。
- 同時に出ると理不尽になる組み合わせは、同時には出ないようになっています。
- エンティティが同じ場所に居続けるのは最大でも 2 分未満です（S は 100 秒以内）。

## デバッグモード

`/rooms admin debug on` で有効になります（オーナーのみ）。

- 部屋の生成、エンティティの出現・消滅、隠れ場所、パネル操作などの通知がチャットとサーバーログに出ます。
- **死亡回避**：デバッグ中は死亡だけが取り消されます。ダメージは通常どおり受けます。
- `/rooms admin debug section` で現在のセクションとセクション表を表示します。

## コマンド

`/rooms` 以下のコマンドです。公開は `restart`・`hard status`・`record` だけで、それ以外は `/rooms admin`（オーナーの Minecraft アカウントのみ。サーバーコンソール・OP・コマンドブロック・`/execute as` は不可）です。

| コマンド | 権限 | 内容 |
|---|---|---|
| `/rooms restart` | 全員 | 周回のやり直し：開始の部屋から 5 部屋以内ならコインなし（所持品はそのまま）でロビーへ戻る（ロビーを作り直し）。部屋ディメンションの外からはロビーへ移動するだけ |
| `/rooms hard status` | 全員 | ハードモードの状態を表示 |
| `/rooms record` / `record <player>` | 全員 | 到達記録（通常・ハード別：最深の部屋と日時、セクション別の最深、周回数、ノーヒット生還の最深、001 からの最深と達成回数、最長の通し）。オフラインの人も名前で見られます |
| `/rooms record top` | 全員 | 最深ランキング（通常・ハード別、上位 10 人） |
| `/rooms record top <v\|b\|u\|s\|h\|f\|a>` | 全員 | そのセクションの 001 から始めた周回だけのランキング（最深と 001〜最後の部屋の達成回数。A は終わりがないので最深だけ。通常・ハード別、上位 10 人） |
| `/rooms record top streak` | 全員 | 1周回で通しで進んだ部屋数のランキング（どこから始めてもよい。「A-500 → A-1199」のように区間も表示。通常・ハード別、上位 10 人） |
| `/rooms admin to <1-500>` | オーナーのみ | ロビーから部屋 N まで生成してワープ（進行をリセット） |
| `/rooms admin deepest` | オーナーのみ | 自分がこれまでに入ったいちばん深い部屋へ（生成済みならそこへワープ、なければそのセクションから作り直し） |
| `/rooms admin tp <section> <部屋>` | オーナーのみ | 指定セクションの指定部屋まで作り直してワープ（ロック無視） |
| `/rooms admin hard on` / `off` | オーナーのみ | ハードモードの切り替え（サーバー全体・ワールドに保存） |
| `/rooms admin debug on` / `off` / `status` / `section` | オーナーのみ | デバッグモードの切り替え・確認、現在のセクション表 |
| `/rooms admin spawn <id>` | オーナーのみ | エンティティを強制出現（同じ排他グループが生存中なら出現しません） |
| `/rooms admin section <id>` / `<id> now` / `<id> <部屋番号>` / `reset` | オーナーのみ | セクション表の変更（ロック中のセクションは不可） |
| `/rooms admin section [<id> lock\|unlock]` | オーナーのみ | セクションの利用可否（既定は PLACEHOLDER・H・F がロック） |
| `/rooms admin give flashlight` / `battery [n]` / `bandage [n]` / `adrenaline [n]` / `charm [n]` / `radar [n]` / `scanner [n]` / `coins <n>` | オーナーのみ | 自分に渡す（所持数へ） |
| `/rooms admin wallet <player> [set <種類> <n>]` | オーナーのみ | 所持数を見る・変える |
| `/rooms admin run reset [player]` | オーナーのみ | 周回の記録を消す（コインなし） |
| `/rooms admin record reset <player>` | オーナーのみ | そのプレイヤーの到達記録を消す（オフラインの人も名前で） |

到達記録は周回中に歩いて進んだ部屋だけを数えます（`/rooms admin to`・`tp`・`deepest` で始めた周回や、ワープ・tp で飛んだ分は数えません）。記録を超えて新しいセクションに入った時と、周回の終わり（生還・死亡）に「自己ベスト更新：A-612」と表示します。記録はワールドに保存されます（`data/roomsmod_records.dat`）。

`/rooms admin spawn` の id：`b20` `b40` `b15` `b30` `b50` `b70` `b90` `b110` `b130` `b155` `b180` `b205` `b230` `b260` `b290`
 `v10` `v25t` `v25l` `v25buffed`（`v25buffed table` / `v25buffed locker`）`v100` `v50`
`s10` `s25` `s45` `s65` `s85` `s105` `s125` `s145` `s165` `s185` `s205` `s225` `s245` `s270` `s300`
 `u20` `u60` `u120` `u200` `u300`
 `h30` `h90` `h150` `h260`
 `f5` `f35` `f100` `f200`
 `placeholder32767` `placeholder65535` `placeholder2147483648`（テスト用。PLACEHOLDER の部屋以外でも出せます）

B / S / U / F の番号はそのエンティティが出始めるセクション内の部屋番号です（H は名前だけで、出現開始は H-30 が H-5、H-90 が H-35、H-150 が H-100、H-260 が H-200）。

### 例

- S を最初から：ロビーの左の壁で `S-001` を選んで GO（または `/rooms admin section s 1` → `/rooms admin to 1`）
- A を最初から：ロビーで `A-001` を選んで GO（または `/rooms admin tp a 1`）
- V の 100 部屋目から：ロビーで `V-100` を選んで GO
- U を最初から：ロビーで `U-001` を選んで GO（または `/rooms admin section u 1` → `/rooms admin to 1`）
